# T-B: Live Consumers of the Clean-Break Ownership Seams

**Track**: T-B — seam consumer enumeration (architecture checkpoint, S0)
**Date**: 2026-08-01
**Owner**: `docs/factory/triga-engine/checkpoint/`
**Scope**: live consumers of the four ownership corrections in
[`GOAL.md`](../GOAL.md) ("Current-to-target ownership corrections"), restricted
to the allowed roots (exempla/, corpus demos' `src/*.fab`, proof/, scripta/,
src/, src-backup-test/, docs/factory/triga-threejs-80/, docs/factory/triga-threejs-90/).

The four seams:

| Seam | Current location | Target owner |
| --- | --- | --- |
| **A** | `material.fab`: `MeshGeometry` | `geometry/data` |
| **A** | `material.fab`: `Mesh` | `renderable/mesh` |
| **B** | `graph.fab`: light fields (`Light`, `AmbientLight`, `DirectionalLight`, `PointLight`) | `lighting/light` + graph attachment |
| **C** | `geometry.fab`: mixed data/layout methods | `geometry/{data,attribute,layout,bounds,batch}` |
| **D** | `scene.fab`: store/query growth | `scene/{store,query}` |

## Method and gate facts

- Every consumer below was found by symbol/import grep across the allowed
  roots, not by building. No builds or commits were run.
- **`scripta/check-compile` is the top gate**: it parses each leaf module by
  name (`math graph material face geometry primitives scene resource triga`),
  runs direct Radix checks on selected exempla, and runs
  `faber run --compile exempla/triga-scene-store.fab` (the generated-Rust
  acceptance path). `check-exempla-inventory` compiles **all 14 documented
  exempla** via `radix check`, then `faber run --compile` for all except a
  4-file allowlist (`triga-geometry-attributes`, `triga-stage4-source-facts`,
  `triga-graphics-pipeline-facts`, `triga-vertex-fragment-stub`).
- `target/faber/src/main.rs` is **generated and gitignored** (regenerated by
  `faber run --compile`); it is a regeneration surface, not a checked-in
  fixture. Current contents confirm the module boundaries that the seams
  target: `mod material { MeshGeometry, Mesh }`, `mod graph {
  AmbientLight, DirectionalLight, PointLight }`, `mod geometry {
  BufferGeometry, BufferAttribute }`, `mod scene { SceneStore }`.
- `proof/capstones/*.json` reference workloads by string under the sibling
  `examples` repo (`examples/triga-capstones/*`); **none reference any seam
  genus or function name**. Zero direct impact for all four seams.
- `src-backup-test/` is **empty** — no consumers.
- **proba coverage**: only `src/math.proba` exists. No seam module has any
  `.proba` coverage; all seam coverage is via exempla.
- The two corpus demos' `tests/run.sh` resolve `triga:*` against
  `$WORKSPACE/triga/src` via a generated `faber.lock`
  (`interface_root = "$WORKSPACE/triga/src"`), then run `faber check` on each
  demo `src/*.fab` and `faber build --package .` (TS browser target). Demo
  `dist/` and `public/` are generated and gitignored; the demo `src/*.fab`
  files are the live consumers.
- **Live gate observation**: `./scripta/check-source` currently **exits 1**.
  `src/geometry.fab:1332 functio geometry_vertex_layout_matches(` trips the
  genus-prefix naming lint (the exempt list has `scene_(`, `camera_(`, … but
  no `geometry_(` exemption). The tree's source gate is red on the geometry
  seam today; a split is the natural place to resolve the shape.

## Seam urgency ordering (cheapest to break first)

1. **Seam B — graph light fields.** Zero live Faber constructors; only
   generated Rust (regenerated) and planned-goal prose. Cheapest break in the
   whole list; do it before Stage 6. Only risk: don't accidentally also split
   `graph/{object,camera}` in the same delivery.
2. **Seam A — Mesh/MeshGeometry out of material.** One constructing exemplum
   (`triga-types-untested.fab`) plus two material-family fixtures that are
   unaffected by this seam alone. Bonus: deletes the `material → graph` reverse
   dependency. Break before Stage 6.
3. **Seam D — scene store/query.** Few consumers but the heaviest gate pinning
   (Stage 2 acceptance + direct Radix check + generated-Rust run all in
   `check-compile`). Requires a Faber nested-package tooling check (DEFER-121)
   and unchanged interface names. Break before Stage 7.
4. **Seam C — geometry split.** Most consumers (2 internal modules, 5 exempla,
   1 corpus demo, Stage 4 reflection seam) and an already-red source gate
   (`geometry.fab:1332` naming lint). Coordinate with Stage 4's reflection
   agreement; preserve accessor names or sequence the rename.
